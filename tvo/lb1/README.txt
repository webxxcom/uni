ЛР №1 ТВО, варіант 9 – накладання шуму Перліна на зображення в кількох потоках (C#, .NET 10, Windows).

Запуск (з теки PerlinFilter):
  dotnet run -c Release -- ..\input.jpg ..\results 11

Аргументи: вхідне зображення, тека результатів, кількість повторів для кожної кількості потоків.
Результати: results\results.csv (час, прискорення, ефективність), results\output.jpg (результат фільтра), results\noise.jpg (шум).
